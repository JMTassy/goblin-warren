# /warren — the scaling constitution

CORE LAW: **meaning is free; state is earned.** Garden change ⊬ Kernel truth.
SCALING LAW: more Garden, not more sovereignty · more goblins, not more rulers ·
more pressure, not more authority · more receipts, not more claims ·
more play, not more ceremony. **A bigger Kernel is probably a weaker Kernel.**

## The sacred loop (never add agents until this stays fun, replayable, inspectable)
goblins propose → operator stamps → Garden mutates → claimable receipts appear
→ Kernel admits only if earned.

## How to grow (one bounded mechanic per slice, verify after EVERY slice)
1. One goblin, one plot, one stamp. 2. Five goblins with vectors. 3. /goal
hivemind. 4. Receipt-memory. 5. Mini-games. 6. Persistent Garden world.
7. Claimable receipt tray. 8. Local LLM flavor. 9. Multi-zone Garden.
10. Optional backend only after the local loop is proven.
After each slice: run every selftest harness; a slice that can't be verified
end-to-end is not done. Commit ≠ admission; branch = proposal surface.

## Goblin lanes (each defined by: role · proposal types · memory source ·
## forbidden actions · success metric · failure mode. NO lane gets admission.)
Builder (world growth) · Jester (holes, contradictions, absurdity) ·
Archivist (memory, receipts, history) · Warden (risks, authority leaks) ·
Artist (beauty, Garden feel) · Economist (resources, tradeoffs) ·
Tester (checks, falsifiable claims).

## Memory law
memory = function(event_log). No hidden mutable memory, ever. Derived views
only: taste, obligation, coalition, proposal-success, denial-pattern,
verified-claim histories — all replayable, all inspectable.
Reducer zone: no Math.random, no Date, no DOM/network; determinism via
seeded hash of event data. Selftests extract the reducer by the
REDUCER-BEGIN/END markers — never rename them.

## Pressures (global pressures, never global authority; each re-ranks, none admits)
goal · obligation · resource · novelty · risk · beauty.

## Selector (authority risk dominates everything)
S(p) = value + falsifiability + reversibility + goal_alignment + novelty
     − complexity − obligation_pressure − authority_risk
with authority_risk weight ≫ obligation_pressure > complexity.

## Epoch discipline (bounded cycles; emit per epoch)
observe → propose → critique → verify → type claims → build obligations →
update pressures → re-rank → operator gate.
epoch: {proposals, selected, tests_run, obligations_opened/closed,
unsupported_closure_count, verified_claim_ratio, authority_violations}.
**If authority_violations > 0: STOP EXPANSION.**

## Zones (complexity grows by zone, not by giant dashboard)
Compost Yard (rejected ideas mutate) · Receipt Forge (claimable actions) ·
Dream Grove (proposals) · Warden Wall (authority risks) · Replay Shrine
(history) · Market (tradeoffs) · Theater (funny visible consequences).

## Verification levels (most features live at 0–3; Level 6 is rare)
L0 playable · L1 replay-deterministic · L2 metrics emitted · L3 selector
pressure works · L4 obligation debt decreases · L5 independent witness ·
L6 kernel admission candidate.

## Claim typing (mandatory in all reports)
WITNESSED (ran it, command citable) / REPORTED (testimony) / CANDIDATE
(inference) / NEEDS_ME (operator decision). Closure vocabulary (validated,
implemented, ready, done, approved) is embargoed without a receipt.
Forbidden morphisms (reject on sight): proposal ↛ state · report ↛ receipt ·
receipt_candidate ↛ admission · dashboard ↛ canon · test_description ↛
test_execution · hivemind_intent ↛ authority · swarm_agreement ↛ receipt ·
collective_pressure ↛ admission · goal ↛ authority.

## Kernel law (scale it by refusing to scale it)
Scale ONLY: receipt schemas, replay tests, admission gates, evidence quality,
CHRONOS, reducer simplicity. Never scale Kernel roles, mythology, or
authority. index.html + selftest.js are frozen V0 canon — byte-identical,
never edited. Every session ends its Warren work at HOLD_FOR_OPERATOR:
the operator's hand is the only admission.
