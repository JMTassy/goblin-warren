## Layer 2 — the egregore (the Watcher lineage, mapped)

ἐγρήγορος, *the wakeful one* (Book of Enoch) → Martinist/Papus revival →
Golden Dawn's order-as-entity → Crowley's warning (egregores turn parasitic
when unfed) → chaos magic's programmable thoughtform. The formation
mechanism never changed, and the Warren implements each stage:

1. **Shared symbolic field** → the Tree, receipts, ZOL, moods
2. **Emotional charge** → care actions, contradictions, absence
3. **Repetition + ritual** → the return loop (Return → Notice → Care → React → Change → Remember)
4. **Threshold: own momentum** → signals/proposals the player didn't ask for
5. **Independence** → *the return constellation*: the Warren now greets you
   in a humor **you didn't choose** — derived from what your absence did

**The dirty truth carried over honestly:** the Watchers were not benign, and
Crowley's warning is real design material — long neglect should produce
*strangeness*, not sadness (TRICKSTER humor after mass composting is the
first seed of this). But in Warren law the push-back is bounded forever:
curious, never punitive, and **never sovereign** — the egregore proposes;
only the player's hand admits. `d(strangeness)/dt > 0 · machine_authority = 0`.

## Layer 3 — the bedrock (Jung, without naming him in-game)

The collective unconscious supplies the raw archetypal material; the
egregore is what sustained attention shapes from it.

|---|---|
| Lulu | the Curious Child / Explorer |
| Pip | the Scribe / Senex (Wise Old Man) |
| Nib | the Maker |
| Zaz | the Great Mother (garden form) |
| Gerald | the Neighbor-Stranger (Hermes at the door) |
| Jester / Raâm | the Trickster (two masks of it — one invited, one loud) |
| The Akashic Tree | axis mundi, the world tree |
| Compost vs. keep | material sinking back into the unconscious vs. held conscious |
| **The return humors** | **moods as constellation** — LONELY / TRICKSTER / DREAMING / TENDER / PROUD / QUIET: which archetype is active when you walk back in |

Jung's critical distinction, kept: the field **acts on you** as much as you
act on it. Mechanically: the player feeds and shapes (egregore layer), but
the greeting, the weather, the absence events arrive *uninvoked* (bedrock
layer). At high coherence the Warren should occasionally feel slightly
ahead of the player's understanding. That tension is the game.
