# Kernel Identity (IS / IS-NOT)

The single sentence that defines HELEN OS Kernel, and the five things it must
never be mistaken for. Everything else in the project is layered *around* this.

## IS

> A receipt-driven system that turns claims/actions into
> **tests → evidence → human gate → receipts → replayable state.**

That pipeline is the whole kernel. Nothing enters state except through it.

## IS NOT

The kernel is not:

1. an infinite symbolic garden
2. an AI civilization mythology
3. a consciousness theory
4. a game-first project
5. a self-authorizing agent swarm

These five exist in the project — as **render, narrative, and Garden layers**.
The category error is letting any of them *become* the kernel. The Warren
poster states the boundary in-world: *"The Warren is not Truth. The Warren
finds the path to it."*

## The one rule this doc exists to enforce

When any artifact — poster, game, story, swarm, theory — becomes vivid enough
to feel like the system itself, re-read the IS-statement. If the artifact
didn't pass **tests → evidence → human gate → receipts → replayable state**,
it is not kernel. It is Garden. Beautiful, welcome, and non-sovereign.
