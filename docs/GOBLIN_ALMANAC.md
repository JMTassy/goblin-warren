## Haikus (after Bashō, gone goblin)

1. Old bog, still and green— / a goblin cannonballs in. / Plip. Nobody claps. 🌱
2. Mushroom after rain: / yesterday there was nothing. / Today, a small hat. 🍄
3. Snail on the cold stone— / slowly, slowly, it arrives. / So does the receipt. 🧾
4. Lantern in the fog: / it lit nothing but itself. / Still, we all showed up. 🏮
5. First frost on the moss— / the goblins argue whose fault. / It was nobody's. 🍂
6. The Tree does not speak. / It writes everything down, though. / Mind what you boop. 🌳
7. Autumn compost sighs— / even the rot has a plan. / Be patient. Be soil. 🌰
