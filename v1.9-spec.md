## The Memory Seed Quest (Pillar: Tool Conjuration)

**Trigger**: After third proposal, a glowing memory seed appears near Pip (hardcoded zone position).

**Maestro prompt**: "A memory wants planting. Choose who should carry it."

**Player choice**: Select from [Pip, Zaz, Lulu, Nib]

**Agent evaluation**:
```
score = 
  preferenceMatch * 3 +
  roleMatch * 4 +
  trust * 0.5 -
  fatigue * 0.7 -
  aversionMatch * 3
```

**Expected outcomes**:
- Pip: Records but refuses to leave Receipt Forge (averts task)
- Zaz: Accepts, plants in Garden (completes step 1)
- Lulu: Takes seed somewhere philosophical/sideways (creates cascade)
- Nib: Tries to repair seed (derails task, possibly funny)

**Systemic lesson**: Best outcome is TWO agents in sequence.
- Pip records memory
- Zaz plants it
- Neither alone could do both

**Maestro conclusion**:
```
TOOL CONJURATION
Pip understood the memory.
Zaz understood the soil.
The best agent was not one.
It was the right sequence.

+15 ZOL
```

**Cascade example** (if Lulu takes seed):
1. Lulu became curious (mood trigger)
2. Lulu moved seed to Mycelial Gate (preference: novelty)
3. Zaz followed glow (observation)
4. Garden Plot unattended (state change)
5. Toxicity rose +4 (world reaction)

Maestro: "One mood changed one path. One path changed the garden."
