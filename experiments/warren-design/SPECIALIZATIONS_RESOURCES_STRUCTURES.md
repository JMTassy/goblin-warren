# SPECIALIZATIONS_RESOURCES_STRUCTURES.md — Levels 4-7 expansion sheet

<!-- authority=false · canon=false · ledger_effect=none · non-sovereign design doc. -->

## Scope — read this first

This document reclassifies a concept-art sheet that reads well as an
**expansion asset sheet** (specialized Goblins, infrastructure, resource
systems) but is **not** the opening adoption loop — it already introduces
several trades, resources, and systems that would overwhelm a first
contact with Bram. Per `AI_LEARNING_SPINE.md`, it belongs at **Levels
4-7**: verify, correct, memory, specialization. It must not be merged with
`ADOPTION_LOOP_ASSET_SPEC.md`, which stays intimate and small on purpose —
the first sheet creates attachment; this one opens systemic depth
afterward.

Functional reading is the operator's own (translated/organized here, French
object names kept where they name a specific concept art asset).

## Specialized Goblins

| Goblin | Role | Later AI-literacy hook |
|---|---|---|
| **Forgeron** (blacksmith) | fabrication, repair, tools | Level 4 (verify) — the blacksmith *claims* a tool is repaired; the player must test it. Level 5 (correct) — player shows which part is still defective. |
| **Collecteur / éclaireur** (scout) | resource search and transport | Level 6 (memory) — must remember which resources are safe, rare, or already harvested; player learns bounded memory isn't automatic. |
| **Chaman** (shaman) | detection of unusual signals, trace analysis | Interprets ambiguous signals — a natural home for Level 8 (conflicting signals) once that level is built out. |

All three converge on the same Level-7 lesson as Bram/Lulu: **good task +
good agent → better result.** The player learns to route work to the
Goblin suited for it (repair → Forgeron, search → Collecteur, interpret →
Chaman), the same specialization intuition Bram/Lulu teach at the
adoption-loop scale, now with more roles to route between.

## Infrastructure

| Structure | Role | Later AI-literacy hook |
|---|---|---|
| **Palissade** (palisade) | security and authorization | Level 9 (governance) — a capability boundary made spatial: something can be capable of crossing but not permitted to. |
| **Maison avec feu** (house with fire) | hearth and persistent memory | Extends the Level-6 memory boundary beyond one Goblin's recall to a shared, place-anchored memory. |
| **Atelier** (workshop) | resource transformation | The site where Forgeron's repair/fabrication claims get made — and where Level 4/5 verify-and-correct actually happens. |
| **Sanctuaire** (sanctuary) | verification or interpretation of signals | A candidate site for Level 10 (evidence) — a place a claim gets checked against the world, not just asserted. |
| **Porte / autel de pierre** (gate / stone altar) | conditional access to a new zone | Structural expression of Level 9 governance — capability (can open) vs. authority (may open). |

## Resources

| Resource | Role | Later AI-literacy hook |
|---|---|---|
| **Champignons lumineux** (luminous mushrooms) | discovery and classification | A concrete object for Level 6 memory practice — "which ones have I already found?" |
| **Armes et armures** (weapons and armor) | repair or sorting | Forgeron's verify/correct material (Levels 4-5). |
| **Viande en cage** (caged meat) | constrained or perishable resource | Introduces resources with a decay/constraint rule — a precursor to priority/policy reasoning (Level 8). |
| **Slime vert** (green slime) | dangerous material requiring rules | A resource that *needs* explicit handling rules before an agent should touch it — pairs naturally with governance (Level 9): capable of handling it ≠ permitted to, without a rule in place. |
| **Jetons rouges** (red tokens) | economy or limited capacity | A bounded resource that forces explicit prioritization — Level 8 material. |
| **Herbes suspendues** (hanging herbs) | categorization and memory | Another concrete Level-6 memory/categorization object. |
| **Baies** (berries) | simple collection and maturity prediction | The simplest resource here — good early Level-4/6 material (predict, then verify the prediction). |

## Where this sheet enters the progression

| Level | What from this sheet applies |
|---|---|
| **4 — Verify** | Forgeron claims a tool is repaired; the player tests it. |
| **5 — Correct** | Player shows Forgeron which part is still defective. |
| **6 — Memory** | Collecteur must remember which resources are safe, rare, or already harvested; champignons lumineux / herbes suspendues / baies are concrete memory objects. |
| **7 — Specialization** | Player learns to assign each task to the suited Goblin: Forgeron to repair, Collecteur to search, Chaman to interpret — same lesson Bram/Lulu teach, more roles. |

Governance (9), evidence (10), and conflicting-signals (8) hooks are noted
above as candidate future homes for Palissade/Porte, Sanctuaire, and
Jetons rouges/Viande en cage respectively, but this sheet's primary,
tested landing zone is **Levels 4-7**.

## What's missing for the opening loop (and why it isn't here)

Everything in this document is deliberately **not** part of adoption or
the first fire — seeing Forgeron, Collecteur, Chaman, five structures, and
seven resource types before the player has even bonded with Bram would
bury the relationship the whole curriculum depends on. The opening loop's
asset needs are covered separately and minimally in
`ADOPTION_LOOP_ASSET_SPEC.md`.
